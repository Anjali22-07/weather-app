-	Built a weather app using weather apis.
-	Integrated with multiple APIs to collect the most reliable weather readings.
-	WeatherNow is a responsive and user-friendly web application that provides real-time weather data for any city entered by the user. Built using HTML, CSS, and JavaScript, the application integrates with the OpenWeather API to fetch and display up-to-date weather information, including temperature, weather conditions, humidity, and wind speed.

Users can simply enter the name of a city into the search field, 
and the application dynamically retrieves and presents the relevant weather data in a clean and intuitive interface. 
Designed with a focus on usability and performance, WeatherNow offers a seamless experience across devices and is an ideal example of API integration in modern web development.
